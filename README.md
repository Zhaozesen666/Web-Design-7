# Портфолио-резюме

Одностраничный сайт-портфолио. Вёрстка Mobile First: базовые стили для телефона, расширения через `@media (min-width: …)`.

## Стек
HTML5, CSS3 (переменные, Flexbox, Grid), JavaScript (без библиотек).

## JavaScript-функционал
- переключение светлой и чёрной темы с запоминанием выбора;
- подсветка текущего раздела в меню при прокрутке (IntersectionObserver);
- фильтр проектов;
- проверка формы обратной связи.

## Как работает JavaScript
- **Переключение темы.** При нажатии на кнопку ◐ у элемента `<html>` меняется атрибут `data-theme` («light» или «dark»). В CSS для каждой темы заданы свои цвета через переменные, поэтому весь сайт перекрашивается сразу. Выбор сохраняется в `localStorage`, и при следующем открытии тема остаётся прежней.
- **Подсветка раздела в меню.** `IntersectionObserver` следит, какой раздел сейчас в центре экрана, и добавляет соответствующей ссылке меню класс `is-active`.
- **Фильтр проектов.** У каждой карточки есть атрибут `data-type` («3d» или «web»). При нажатии на кнопку фильтра скрываются карточки, тип которых не совпадает с выбранным; кнопка «Все» показывает всё.
- **Проверка формы.** При отправке проверяются три поля: имя (от 2 символов), почта (по шаблону name@example.com) и сообщение (от 10 символов). Если поле неверное, под ним появляется красное сообщение об ошибке. Если всё верно, открывается почтовый клиент с готовым письмом.

## Как реализован Mobile First
Базовые стили в `style.css` написаны для телефона: одна колонка, горизонтальное меню с прокруткой. Для планшета (от 640px) и компьютера (от 960px) добавлены только медиазапросы `min-width`, которые включают две и три колонки карточек и более крупные отступы. Сайт проверялся в DevTools на разных размерах экрана.

## Журнал изменений и найденных проблем
Я проверял сайт в браузере, находил проблемы и ставил задачи нейросети на исправление. Исправления в коде вносила нейросеть по моим замечаниям.

| Что обнаружено или решено мной | Что сделано |
|---|---|
| Тёмная тема должна быть чёрной | Цвета в `style.css` заменены на чёрный фон (`#000`) |
| Нужны мои работы | Добавлены три 3D-рендера из Blender, изображения сжаты до размера около 100 КБ и лежат в папке `images` |
| Картинки отображались обрезанными и в одном размере | В `style.css` убрана принудительная пропорция 4:3, изображения показываются целиком |
| Переключатель темы перестал работать | Причина: при недоступном `localStorage` скрипт выдавал ошибку и не подключал обработчик кнопки. Обращение к `localStorage` обёрнуто в `try/catch` |
| Дополнительная проверка кода | В форме обращение к полям переписано через `document.getElementById`, чтобы поле `name` не путалось с `window.name` |
| Нужно объяснить работу сайта | Добавлены разделы «Как работает JavaScript» и «Как реализован Mobile First» |
